## 8. 확인 방법

- 화면 데이터: 관리자 로그인 뒤 3절의 경로를 GET으로 한 번씩 읽어 상태 코드와 건수만 남겼다.
- 전송 통제: `/api/tasks/1/e2-flow`의 시도별 판정·사유·방법·경로 패턴을 셌다. `diagnosis-run`의 `run.execution.counts`와 대조했다.
- 대상 로그: VAmPI 접근 로그에서 색 코드를 지우고, 메서드·경로 틀·상태로 셌다.
- 보고서: 내부용·공유용 HTML에서 제목 목록과 비밀값 꼴 문자열의 건수만 셌다. 본문은 옮기지 않았다.
- 로그 오류: 제품 컨테이너 로그를 1분마다 오류·경고 줄 건수로 요약했다(정상 운영 문구 제외).
