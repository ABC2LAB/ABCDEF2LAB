# 선택 후보 실행과 E③ 선언의 분리

## 적용 범위

`llm/v1`의 별도 승인된 비 IDOR 후속 실행만 후보 전용 권위를 발급한다. 원본 진단의 E③ 선언과 판정은 그대로 두고, 후속 실행은 원본과 다른 task/run 및 새 E② 권위를 사용한다. 활성 선언이 있다는 이유만으로 후속 실행을 차단하지 않지만, 후속 실행에서 E③ 선언·정책·대상 참조 파일, 목적 규칙, 확정 몫, 쓰기 동의 또는 판정을 발급하지 않는다.

## 발급 전제와 확인

- 원본 task와 후보 digest, 사용자 승인 계획 digest, 현재 대상 승인·범위·제외 경로를 발급 전과 각 송신 전에 다시 확인한다.
- 후보 전용 정책은 승인한 정확한 GET/HEAD만 포함하고 인증 세션·외부 시험 계정을 결속하지 않는다. 인증 또는 계정이 필요한 후보는 계속 보류한다.
- 발급된 정책과 authority digest가 일치하고, 새 task/run과 승인 사건이 동일한 검증 요청에 결속돼야 한다.
- 후보 실행의 E③ 필드와 목적 규칙·동결 파일이 전부 없어야 한다. 이를 검사하지 못하면 송신 전에 실패한다.
- 일반 진단의 발급 경로는 E③ 선언 동결, 목적 규칙과 확정 몫을 계속 발급한다. 후보 전용 옵션은 일반 진단에서 선택할 수 없다.

후속 실행의 관찰은 기존 E② Host 감사·봉인과 비 IDOR 판정 경로에만 들어간다. E③ 발급·판정 또는 접근통제 지도에는 넣지 않는다. 현재 후보 전용 실행은 원본 관찰이 불충분하면 확정·부정을 금지하는 기존 판정 기준을 유지한다.
